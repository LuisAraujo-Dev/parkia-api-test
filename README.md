# 🅿️ PARKIA – Plataforma de Estacionamentos Inteligentes

Desafio técnico para gestão de vagas de estacionamento com regras de negócio realistas, controle de ocupação e cálculo de tarifas automatizado.

---

## 🚀 Tecnologias Utilizadas

### Backend
- **NestJS v11** (Framework Node.js progressivo)
- **TypeScript** (Tipagem estática e segurança)
- **TypeORM** (Mapeamento Objeto-Relacional)
- **PostgreSQL** (Banco de dados relacional)
- **Class Validator/Transformer** (Validação rigorosa de DTOs)

### Frontend
- **React 18** (Biblioteca de interface)
- **Tailwind CSS v4** (Estilização de alto desempenho via CSS-engine)
- **Lucide React** (Pacote de ícones)
- **Axios** (Integração com API)

---
